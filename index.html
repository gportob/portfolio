#About me

I hold degrees in Software Engineering and in Advertising — a combination that helps me bring together technology, design and creativity in every project I build.

I focus on building digital products that combine strong performance, accessibility and an interface that makes sense for the people using it. I enjoy turning a design into clean code — and thinking through every interaction detail, from hover states to error states.

I work mainly with HTML, CSS and JavaScript, but I also move between PHP and React when a project calls for it. I care a lot about SEO, AEO, AIO and GEO — because a beautiful interface is worth little if no one can find it.
